¿Qué es TechDay?

Un TechDay es una jornada dedicada a mostrar las últimas tendencias en tecnología, automatización e innovación industrial, enfocada en mejorar la productividad y competitividad de las empresas. Su objetivo principal es que los participantes puedan vivir la tecnología de manera práctica, explorando soluciones aplicables a sus procesos y proyectos, y generando conexiones estratégicas con proveedores y expertos.

TALLERES

Desarrollo Frontend

El desarrollo front end es aquel que da una estructura a los datos que aparecen en una interfaz gráfica, con el fin de optimizar la experiencia del usuario.

PHP y MySQL

PHP es un lenguaje de programación de código abierto diseñado específicamente para el desarrollo web.

MySQL es un sistema de gestión de bases de datos relacional (RDBMS) de código abierto ampliamente utilizado para almacenar y administrar datos estructurados.

Diseño UX/UI

UX se enfoca en la experiencia global del usuario con un producto o servicio, UI se concentra en los aspectos visuales y de interacción de la interfaz.

Introducción a Inteligencia Artificial

La inteligencia artificial (IA) se refiere al desarrollo de sistemas informáticos capaces de realizar tareas que normalmente requieren inteligencia humana, como el razonamiento, el aprendizaje y la percepción
